# Aula 01: Ferramentas para inspecionar a Web

Siga o **Roteiro de práticas da Aula 01** (PDF no Google Classroom).

**Importante:** neste repositório, a Aula 01 fica dentro desta pasta. Antes de executar os comandos do roteiro, entre nela:

```
cd aula01-ferramentas
```

Assim, caminhos como `01-rede/ping-ifce.txt` funcionam exatamente como no roteiro.

| Nº | Pasta | Ferramentas |
|---|---|---|
| 01 | `01-rede` | ping, nslookup, tracert |
| 02 | `02-devtools` | DevTools |
| 03 | `03-curl` | curl, ViaCEP, httpbin |
| 04 | `04-get-post` | curl, DevTools, httpbin |
| 05 | `05-insomnia` | Insomnia |
| 06 | `06-desafio` | curl, webhook.site (opcional) |
