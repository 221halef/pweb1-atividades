# Aula 02: PHP e HTTP na prática

## Como rodar

Abra um terminal **dentro desta pasta** (`aula02-php-http`) e execute:

```
php -S localhost:8000 -d display_errors=1 -d output_buffering=0
```

Deixe esse terminal aberto: ele é o **log do servidor**. Use **outro terminal** para os comandos `curl.exe`.
